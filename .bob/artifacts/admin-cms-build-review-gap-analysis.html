Identified Gaps — by Priority

🔴 Missing — /admin/ads route + Ads management

The Platform Overview (Part 5) defines two ad placements — a homepage banner (between hero and Today on Set Life) and one inline article slot — sold and uploaded manually. The nav lists /admin/ads. There is no ads table action, no AdsForm component, and no route. This is the only route in the spec that is completely absent.

🟡 Gap — Scheduled publishing not implemented

Platform Overview §6 says posts can be set to Scheduled and auto-publish at a future date/time. The current savePost action only knows "draft" status on insert. There is no scheduled_at column write, no UI datetime picker for scheduling, and no mechanism (cron or background job) to flip status to "published" at the right moment.

🟡 Gap — /admin/gates not linked in nav

The /admin/gates page exists and works, but the AdminLayout nav array does not include a link to it. It's only reachable by typing the URL directly. The dashboard tiles already surface individual gate statuses, but the standalone gates page provides the full table view and is referenced in the overview.

🟡 Gap — TiptapEditor missing alt-text prompt on image insert

The Platform Overview calls out "required alt text" for images. The TiptapEditor inserts images with alt: "" (empty string) both on drag-and-drop and on toolbar upload. There is no prompt or field for the contributor to enter alt text at insert time.

🟣 Minor — posts/[id] page has no link back to the live story

When editing a published post, there's no "View on site" link to /story/[slug]. Minor UX gap but useful for contributors to verify what went live.

🟣 Minor — submissions page has no "unreviewed first" sort or filter

getAllSubmissions orders by created_at DESC only. Once there are many submissions, reviewed and unreviewed are mixed. A filter or default sort putting unreviewed first would be more practical.

🟣 Minor — MediaLibrary refreshes via a second DB query after upload

After uploading, MediaLibrary fires a fresh Supabase select to get the newest row, rather than using the URL returned by uploadMedia. This works but is an extra round-trip; the upload already returns the public URL and the filename is available from the file object.

What Is Not Missing

  • All 9 server actions (posts, authors, issues, products, honorees, submissions, admin-auth) are present and correctly use the Supabase server client
  • Middleware auth guard correctly redirects unauthenticated requests and bounces logged-in users away from /admin/login
  • The exclusive is_current logic for magazine issues (only one issue can be current at a time) is correctly implemented
  • Reading time is auto-calculated on every save from the body JSON word count
  • Revision history is recorded on every save (both insert and update)
  • All revalidatePath calls are in place so published content appears on the public site without a redeploy
  • The dashboard tile grid mirrors the exact homepage section order from the Platform Overview
  • Category-specific meta fields cover all structured content types: review scores, video URLs, opportunity deadlines, festival dates, production stage, credits lists, platform badges
  • The three custom Tiptap block types from the spec (credits list, platform badges, callout box) are all implemented — credits-list and badges as MetaFieldsPanel types, blockquote as pull quote
